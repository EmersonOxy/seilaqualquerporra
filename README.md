# Controlador FPS

Protótipo desktop para Windows 10 e 11 de 64 bits, desenvolvido em C# com raylib.

[Baixar o instalador](https://github.com/EmersonOxy/seilaqualquerporra/releases/latest/download/ControladorFPS-win-Setup.exe)

Instale uma vez e use o atalho **Controlador FPS**. Quando houver uma nova versão, pressione **F6** dentro do jogo para atualizar. O jogo pode ser aberto offline.
